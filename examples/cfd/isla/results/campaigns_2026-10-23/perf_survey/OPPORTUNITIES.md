# ISLA 0.13.0 performance opportunities, ranked (PERF-SURVEY, 2026-10-25)

Prototype branch for #1 and #2: `psharpe/isla-perfsurvey-fusedpad` 80a58e1e8 (local worktree, not pushed): ISLA directory 453 passed / 0 failed on CPU (382714), 735 passed / 0 failed on a GB300 with every CUDA test (382761).

Base: origin/psharpe/isla b86c7391d (ISLA 0.13.0), GB300, bf16, the recipe's own configs. Step shares come from
PROFILE (`profile/PROFILE.md`, job 382020): DrivAerML Volume whole boundary (drv) 1,190 ms / 143 GiB; AeroZoo (az)
716 ms / 126 GiB; AirfRANS with far field (af) 530 ms compiled / 895 eager; lug 234 ms compiled / 394 eager;
DrivAerML Surface option A (drs) 246 ms / 66 GiB; 4-GPU DDP drv 1,244 ms (1,360 with the real loader).
The rerun trains every dataset with compile_blocks (FREEZE-PLAN; eager only if certification fails), so the `_cb`
columns are the relevant ones for af and the lug.

Exactness classes: **B** bitwise; **C** certified within rounding (float64 at roundoff, float32/bf16 at the base's
distance); **N** numerics change with a measured bound. Gain: **M** measured, **E** estimated.
"Fit" scores Peter's screen: exact first, kernels as optional fast paths with a torch reference, generic speedups in the
library, small diffs (removals free), per-iteration time with memory, no magic constants, execution choices from sizes.
